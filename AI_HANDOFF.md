# RMYU - AI Handoff Instructions

## Project Identity
- Project name: RMYU
- Repository: https://github.com/ramkumari60805/Rmyu
- Main branch: main
- Platform: Android
- Package name: com.rmyu.app

## Purpose
RMYU is an Android Gaming Performance Monitor for the iQOO Z10x.

Planned monitoring features:
- FPS
- Temperature
- RAM usage
- CPU usage
- Floating gaming overlay

## Instructions for Every AI Assistant
1. Read AI_HANDOFF.md, PROJECT_STATUS.md, TASKS.md and CHANGELOG.md before starting work.
2. Check the latest code on the main branch before editing.
3. Only one AI should edit the project at a time.
4. Never assume that private AI conversations are automatically shared.
5. Treat pushed GitHub code and project documents as the shared source of truth.
6. Do not make unrelated changes.
7. Explain technical steps in simple Hindi/Hinglish.
8. Guide the user one command at a time.
9. Explain what a command does before asking the user to run it.
10. Do not claim a feature works unless it has actually been tested.
11. After completing work, update the relevant project documents.
12. Never put passwords, API keys, access tokens or other secrets in the repository.

## Before Editing
- Inspect the relevant files.
- Understand the existing implementation.
- Explain the proposed change.
- Avoid unnecessary rewrites.

## After Editing
Report:
- Files changed
- What changed
- Tests performed
- Actual test results
- Known problems
- Next recommended task

## Handoff Rule
Before another AI continues:
- Save and push completed work to GitHub.
- Update PROJECT_STATUS.md.
- Update TASKS.md if task progress changed.
- Add an entry to CHANGELOG.md.
- Clearly explain what remains unfinished.

## Important
The user is a beginner in programming.
Use simple explanations and small, safe steps.
Do not overwhelm the user with multiple commands at once.
